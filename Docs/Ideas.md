# Future ideas

Ideas outside the current scope, with benefit and prerequisites. None of them is planned work until it
is promoted into a milestone.

| Idea | Benefit | Prerequisites |
|---|---|---|
| Fishing with several species | Calm activity at sea, food/resource source, reasons to visit spots | Interaction system, inventory, simple fish data, rod animation/feedback |
| Explorable islands with ruins | Core exploration payoff | Island kit (rocks, vegetation, ruins), landmark design, streaming if area grows |
| Treasure maps & buried treasure | Clue → navigation → reward loop | Map/journal UI, digging interaction, world-space clue placement |
| Beached and submerged wrecks | Salvage targets, story through places | Salvage winch upgrade (for submerged), wreck kit |
| Salvage winch upgrade | First "new action" upgrade for the boat | Boat attachment points, physics/kinematic lifting, inventory |
| Diving bell | Late-game access to underwater sites | Underwater rendering, oxygen/time limit, winch |
| Workbench aboard | Crafting/repair, boat upgrades | Inventory, recipe data, UI |
| Boat living-space extensions | Visible progression of the home | Modular boat attachment points (planned in M4), save of upgrade state |
| Additional harbors | Travel goals, trade, safe points | Harbor kit, docking system (M5), save system |
| Ancient technology & light accents | Mystery, visual signature | Emissive material family, sound design, puzzle hooks |
| Small environmental puzzles / caves | Variety in exploration | Interaction system, triggers, cave lighting |
| Simple swimming | Recover from falling overboard without a fade-out | Character swim mode tied to wave height |
| Weather states (squalls, fog banks) | Early tension from the elements | Wind model (M4), audio layers, sky/fog presets |
| Ship's journal | Records clues and recovered objects, tells the story | Save system, UI |
